# QMS Complaints AI

The QMS Complaints AI is a React app designed to automate the manual processes involved in complaint management. This system classifies complaints into appropriate subcategories and assigns correct priorities and levels to each complaint. By automating these tasks, the QMS Complaint System enhances efficiency, reduces human error, and ensures a more consistent approach to complaint management.

## Prerequisites

- Node (v18.17.0)
- Npm

## Installation

Clone the repository:

```sh
git clone git@github.com:EliLillyCo/complaints-qms-ui.git
cd complaints-qms-ui
```

Install all packages:

```sh
npm install
```

In order to run the application in your local environment type the following command:

```sh
npm start
```

The application runs on **http://localhost:3000**

## Running unit tests and linter

To run unit tests execute:

```sh
npm test
```

To run the linter execute:

```sh
npm run lint
```

## Building

To create an optimized production build of the application execute:

```sh
npm run build
```

**mq-qms-queue-narrative-lambda-dev** is an AWS Lambda function designed to handle the uploading of narrative data for Lilly-Complaints.
**mq-qms-queue-narrative-lambda-dev**
    - Purpose: Queues the narrative in Amazon SQS for inference. 
    - Input: Narrative details from DynamoDB. 
    - Output: SQS message. 
This repository contains the source code, configurartion, and deployment instruction(if any) for the Lambda function

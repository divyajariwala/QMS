# RCA Analysis Database Schema Documentation

## Table: `rca_analysis`

This table stores the Root Cause Analysis (RCA) generated by AI for each deviation in the quality management system.

## Schema Structure

### Primary Fields

| Column | Type | Description |
|--------|------|-------------|
| `id` | SERIAL | Auto-incrementing primary key |
| `deviation_id` | VARCHAR(50) | Foreign key to deviations table (UNIQUE) |

### Issues Section

| Column | Type | Description |
|--------|------|-------------|
| `issues` | TEXT | Detailed description of all issues identified |
| `issues_category` | VARCHAR(100) | Category classification for the issues |

### Major Root Cause Category Section

| Column | Type | Description |
|--------|------|-------------|
| `major_root_cause_category` | VARCHAR(100) | Primary category name |
| `major_root_cause_category_explanation` | TEXT | Detailed explanation (currently same as category) |

### Near Root Cause Section

| Column | Type | Description |
|--------|------|-------------|
| `near_root_cause` | TEXT | Description of the immediate/proximate cause |
| `near_root_cause_category` | VARCHAR(100) | Category classification |

### Root Cause Section

| Column | Type | Description |
|--------|------|-------------|
| `root_cause` | TEXT | Description of the fundamental/systemic cause |
| `root_cause_category` | VARCHAR(100) | Category classification |

### Metadata

| Column | Type | Description |
|--------|------|-------------|
| `created_at` | TIMESTAMP WITH TIME ZONE | When the RCA was first created |
| `updated_at` | TIMESTAMP WITH TIME ZONE | When the RCA was last updated |
| `created_by` | VARCHAR(100) | User who created/triggered the RCA |

## Valid Categories

The following categories are used across different sections:

- **Procedure issue** - Problems related to documented procedures
- **Process/manufacturing equipment issue** - Equipment or process-related problems
- **Company personnel issue** - Human error or personnel-related issues
- **Training issue** - Lack of training or inadequate training
- **System/software issue** - IT system or software problems
- **Documentation issue** - Problems with documentation quality or availability
- **Quality control issue** - QC process or oversight problems

## Constraints

1. **Foreign Key**: `deviation_id` references `deviations(deviation_id)` with CASCADE delete
2. **Unique Constraint**: Only one RCA per deviation (can be updated)
3. **Indexes**: 
   - `idx_rca_deviation_id` on `deviation_id`
   - `idx_rca_major_category` on `major_root_cause_category`

## Triggers

- **update_rca_updated_at**: Automatically updates `updated_at` timestamp on any UPDATE operation

## Query Examples

### Get RCA for a specific deviation
```sql
SELECT * FROM rca_analysis 
WHERE deviation_id = 'DV-12345';
```

### Get all RCAs by major category
```sql
SELECT deviation_id, major_root_cause_category, created_at
FROM rca_analysis
WHERE major_root_cause_category = 'Company personnel issue'
ORDER BY created_at DESC;
```

### Get recent RCAs
```sql
SELECT deviation_id, major_root_cause_category, created_at
FROM rca_analysis
ORDER BY created_at DESC
LIMIT 10;
```

### Update an existing RCA
```sql
UPDATE rca_analysis
SET 
    issues = 'Updated issues description',
    updated_at = CURRENT_TIMESTAMP
WHERE deviation_id = 'DV-12345';
```

## Migration Notes

If you need to add this table to an existing database:

1. Ensure the `deviations` table exists with `deviation_id` as primary key
2. Run the `schema.sql` file
3. Verify indexes are created
4. Test the trigger with an UPDATE statement

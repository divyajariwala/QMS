# RCA Analysis Database Schema Documentation

## Table: `rca_analysis`

This table stores the Root Cause Analysis (RCA) generated by AI for each deviation in the quality management system. Each RCA includes both AI-generated text descriptions and categorized classifications based on the ABS Root Cause Map™ taxonomy.

## Schema Structure

### Primary Fields

| Column | Type | Description |
|--------|------|-------------|
| `id` | SERIAL | Auto-incrementing primary key |
| `deviation_id` | VARCHAR(50) | Foreign key to deviations table (UNIQUE) |

### Issues Section (Problem Category)

| Column | Type | Description | UI Component |
|--------|------|-------------|--------------|
| `issues` | TEXT | AI-generated description of all issues/causal factors identified | Text area (read-only/editable) |
| `issues_category` | VARCHAR(100) | Dropdown category from predefined list (e.g., "Company personnel issue") | **Blue dropdown** |

**Available Categories:**
- Company personnel issue
- Procedure issue
- Training issue
- Equipment issue
- Process/manufacturing equipment issue
- System/software issue
- Documentation issue
- Quality control issue
- Communication issue
- Supervision issue
- External factors
- Other

### Major Root Cause Category Section

| Column | Type | Description | UI Component |
|--------|------|-------------|--------------|
| `major_root_cause_category` | VARCHAR(100) | One of 3 ABS major categories | Text display |
| `major_root_cause_category_explanation` | TEXT | Same as category (for compatibility) | Hidden |

**Available Categories:**
- Equipment/Software Issues
- Personnel Issues
- Other Issues

### Near Root Cause Section

| Column | Type | Description | UI Component |
|--------|------|-------------|--------------|
| `near_root_cause` | TEXT | AI-generated description of immediate/proximate cause | Text area (read-only/editable) |
| `near_root_cause_category` | VARCHAR(100) | Specific ABS subcategory (e.g., "Procedure Issue") | **Blue dropdown** |

**Available Categories (Personnel Issues):**
- Procedure Issue
- Training/Guidance Issue
- Human Factors Issue
- Tech/Craftsman Issue
- Supervision Issue
- No Communication or Not Timely
- Company Issue
- Third Party/Personnel Issue

**Available Categories (Equipment/Software Issues):**
- Design Issue
- Equipment Reliability Issue
- Procedure/Instruction Issue
- Materials/Parts Issue
- Software Issue
- Utility/Support Equipment Issue
- Other Equipment Issue

### Root Cause Section

| Column | Type | Description | UI Component |
|--------|------|-------------|--------------|
| `root_cause` | TEXT | AI-generated description of fundamental/systemic cause | Text area (read-only/editable) |
| `root_cause_category` | VARCHAR(100) | Specific root cause from ABS taxonomy (e.g., "Procedure Not Followed") | **Blue dropdown** |

**Example Categories (for Procedure Issue):**
- Procedure Not Performed Correctly
- Procedure Not Used
- Procedure Not Followed
- Change Control Issue
- Procedure Inadequate
- Procedure Not Available
- Procedure Difficult to Use

*(100+ specific categories available - see `abs_categories.json` for complete list)*

### Metadata

| Column | Type | Description |
|--------|------|-------------|
| `created_at` | TIMESTAMP WITH TIME ZONE | When the RCA was first created |
| `updated_at` | TIMESTAMP WITH TIME ZONE | When the RCA was last updated |
| `created_by` | VARCHAR(100) | User who created/triggered the RCA |

## Valid Categories

The following categories are used across different sections:

- **Procedure issue** - Problems related to documented procedures
- **Process/manufacturing equipment issue** - Equipment or process-related problems
- **Company personnel issue** - Human error or personnel-related issues
- **Training issue** - Lack of training or inadequate training
- **System/software issue** - IT system or software problems
- **Documentation issue** - Problems with documentation quality or availability
- **Quality control issue** - QC process or oversight problems

## Constraints

1. **Foreign Key**: `deviation_id` references `deviations(deviation_id)` with CASCADE delete
2. **Unique Constraint**: Only one RCA per deviation (can be updated)
3. **Indexes**: 
   - `idx_rca_deviation_id` on `deviation_id`
   - `idx_rca_major_category` on `major_root_cause_category`

## Triggers

- **update_rca_updated_at**: Automatically updates `updated_at` timestamp on any UPDATE operation

## Data Flow: AI Generation → Database

### Step 1-4: Generate Text
```
Investigation Summary → AI Processing
    ↓
Issues Text: "The analyst generated duplicate..."
Major Category: "Personnel Issues"
Near Cause Text: "The analyst failed to follow..."
Root Cause Text: "Procedure Not Followed due to..."
```

### Step 5: Categorize
```
All Generated Texts → AI Categorization
    ↓
{
  "issues_category": "Company personnel issue",
  "near_root_cause_category": "Procedure Issue",
  "root_cause_category": "Procedure Not Followed"
}
```

### Step 6: Save to Database
```
INSERT INTO rca_analysis (
    issues, issues_category,           -- Text + Category
    major_root_cause_category,         -- Category only
    near_root_cause, near_root_cause_category,  -- Text + Category
    root_cause, root_cause_category    -- Text + Category
)
```

## Query Examples

### Get RCA for a specific deviation
```sql
SELECT * FROM rca_analysis 
WHERE deviation_id = 'DV-12345';
```

### Get all RCAs by major category
```sql
SELECT deviation_id, major_root_cause_category, created_at
FROM rca_analysis
WHERE major_root_cause_category = 'Company personnel issue'
ORDER BY created_at DESC;
```

### Get recent RCAs
```sql
SELECT deviation_id, major_root_cause_category, created_at
FROM rca_analysis
ORDER BY created_at DESC
LIMIT 10;
```

### Update an existing RCA
```sql
UPDATE rca_analysis
SET 
    issues = 'Updated issues description',
    updated_at = CURRENT_TIMESTAMP
WHERE deviation_id = 'DV-12345';
```

## Migration Notes

3. Verify indexes are created
4. Test the trigger with an UPDATE statement

## Indexes for Performance

```sql
-- Primary lookup
CREATE INDEX idx_rca_deviation_id ON rca_analysis(deviation_id);

-- Category filtering (for analytics and trending)
CREATE INDEX idx_rca_major_category ON rca_analysis(major_root_cause_category);
CREATE INDEX idx_rca_issues_category ON rca_analysis(issues_category);
CREATE INDEX idx_rca_near_cause_category ON rca_analysis(near_root_cause_category);
CREATE INDEX idx_rca_root_cause_category ON rca_analysis(root_cause_category);

-- Date filtering
CREATE INDEX idx_rca_created_at ON rca_analysis(created_at);
```

## Analytics Queries

### Category Distribution
```sql
SELECT 
    issues_category,
    COUNT(*) as count,
    ROUND(COUNT(*) * 100.0 / SUM(COUNT(*)) OVER(), 2) as percentage
FROM rca_analysis
WHERE created_at >= CURRENT_DATE - INTERVAL '30 days'
GROUP BY issues_category
ORDER BY count DESC;
```

### Trending by Root Cause Category
```sql
SELECT 
    root_cause_category,
    DATE_TRUNC('week', created_at) as week,
    COUNT(*) as count
FROM rca_analysis
WHERE created_at >= CURRENT_DATE - INTERVAL '90 days'
GROUP BY root_cause_category, week
ORDER BY week DESC, count DESC;
```

### Hierarchical Category Analysis
```sql
SELECT 
    major_root_cause_category,
    near_root_cause_category,
    root_cause_category,
    COUNT(*) as count
FROM rca_analysis
GROUP BY major_root_cause_category, near_root_cause_category, root_cause_category
ORDER BY count DESC
LIMIT 10;
```
